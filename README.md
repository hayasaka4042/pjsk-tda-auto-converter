# PJSK → TDA 自動轉換器

這是 Blender 4.2.22 的動畫轉換插件，用來把 PJSK／MMD Action 轉換到常見 TDA 骨架。v1.2.0 不再綁死單一模型的英文骨名與 Rest Pose。

## 最快使用方式

1. 在 Blender 的 `編輯 → 偏好設定 → 附加元件 → 從磁碟安裝` 選擇 `PJSK_TDA_AutoConverter.zip`。
2. 匯入 TDA 模型與動作；場景只有一個相容骨架時不必手動指定，否則請選取目標骨架。
3. 在 3D View 右側的 `PJSK→TDA` 面板按下 `轉換所選 Action`。

沒有在面板指定 Action 時，插件會使用目標骨架目前正在播放的 Action。轉換完成後會自動切換到新 Action。

## 插件會自動處理

- 依來源／目標 Rest Pose 的實際矩陣關係轉換動作。
- 自動辨識常見英文骨名、日文骨名，以及 MMD Tools 的 `name_j`／`name_e`。
- 支援 `左足`、`Leg_L`、`Leg.L` 等常見命名格式，不必先手動改骨名。
- 使用每支模型自己的 Rest Matrix；不再要求和內建 TDA 模板完全相同。
- 自動處理常見 TDA 肩輔助、腰取消與 D 腿鏈的階層差異。
- `Dummy_L/R` 存在時會轉換；模型沒有這兩個非核心輔助骨時會安全略過。
- 自動關閉左右腿與腳尖 IK，並在完整輸出範圍逐幀確認沒有重新啟用。
- 自動把實際輸出骨切到 Quaternion 模式。
- 保留原輸入 Action，不覆蓋既有輸出。
- 保持 Quaternion 連續，不建立 Scale 曲線。
- 驗證輸出 Pose 矩陣，失敗時回復原 Action 與原 IK 狀態。
- 在 Blender Text Editor 建立中文可讀的驗證報告。

## 會產生的資料

- `<輸出名稱>`：轉換後可直接播放的新 Action。
- `<輸出名稱>_LowerBody_WORLD_BAKE`：進階檢查用的 LowerBody 世界空間記錄。
- `<輸出名稱>_validation.txt`：轉換範圍、誤差、IK 狀態與來源保護結果。

## 適用範圍

- Blender 4.2.22 LTS。
- 具備標準 TDA／MMD 身體、手指、腿部與足先 EX 語意骨的常見 TDA 模型。
- PJSK 相容的骨架 Action。

這個插件不負責匯入 PMX／VMD，也不是腳底接觸或腳滑修正器。它不會自動建立缺骨、修骨架或猜測歧義骨名。除 `Dummy_L/R` 外，必要語意骨缺失時會停止；完整輸出矩陣驗證不通過時也會恢復原 Action 與 IK 狀態。

## 常見訊息

- `場景中有多個 TDA 骨架`：先選取要轉換的骨架再按一次。
- `請先選擇輸入 Action`：先把動作套到骨架，或在面板的「輸入 Action」選擇動作。
- `TDA 骨架缺少必要語意骨`：列出的核心骨不存在，插件不會自行造骨。
- `TDA 骨名有歧義`：同一語意找到多個同等候選，請先整理模型骨名；插件禁止猜測。
- `腿部 IK 在 frame ... 被重新啟用`：Action、Driver 或其他設定正在控制 IK；插件已停止並恢復原狀。

## v1.2.0 實測範圍

- 原英文骨名 TDA：完整 1–4036 幀矩陣回歸通過。
- 全套日文骨名：62／62 語意骨辨識與 Action 路徑重映射通過。
- 僅使用 MMD 日文欄位、任意 Blender 骨名：62／62 辨識通過。
- 原始 PMX 骨名抽查：Tda式初音ミク 62／62、PPPP Miku 60／60、PPPP Teto 60／60；後兩者安全略過缺少的 `Dummy_L/R`。

「支援大部分 TDA」不代表支援任意自製骨架。模型若刪除核心骨、把左右骨混用，或既有 Constraint 讓輸出無法重現目標矩陣，插件會明確 FAIL。
